Grid Room 1968
This is a Learnscape-style explorable. A dispatch order carries real state through a reduced power-system model. Every station performs a real calculation or control step.
How much of it is real
Computed live: load forecast, reserve requirement, generator dispatch, frequency deviation, governor response, simplified ACE, AGC correction, generator ramping, and the frequency trace. All live arithmetic is in js/model.js.
Scaled down: the game uses three generators and one tie line instead of a full utility network. The time constants are shortened so the mechanism is visible.
Assumed / modeled: generator sizes, costs, inertia, governor droop, ramp limits, control-area bias, and 1968 SDG&E operating details are representative, not claimed as archival plant data.
Historical anchors: the 101 Ash Street headquarters was completed in 1968. The Coronado Bridge was under construction in 1968 and opened in 1969. The world art is reconstructed from those facts, not a literal floor plan.
Deliberately simplified: the COBOL and FORTRAN parsers recognize a small teaching subset. They are not full language interpreters. The code you write changes real model parameters and formulas; the compiler experience is game scaffolding.
Controls
Start the shift, watch the control order travel, and write the requested code when it reaches the keypunch and AGC stations. Click a station to inspect it. Drag to pan and use the mouse wheel to zoom.
